# Security and privacy

Yogurt records meetings, so it handles sensitive data. This document explains
what leaves your computer, what stays on it, how the OpenAI key is stored, and
what the app does to protect itself.

## Reporting a vulnerability

**Don't open a public issue.** Use **Security → Report a vulnerability** in this
repository (GitHub private reporting). Describe the problem, the version and,
if possible, how to reproduce it. Only the latest version receives fixes.

## What leaves your computer

Only calls to the **OpenAI API**, made with **your** key:

| Sent | Purpose |
| --- | --- |
| Audio of each meeting block (`.webm`) | Transcription |
| Transcript, your notes, speaker names and the *Instructions for the summary* | Writing the minutes and the title |

The app has no telemetry, no analytics, no server of its own and no automatic
update check. OpenAI's handling of this data is governed by its API terms;
check OpenAI's current data policy before recording sensitive content.

## What stays on your computer

In `%APPDATA%\Yogurt\`:

- `meetings\<id>\` — audio, notes, transcript and minutes for each meeting, as
  ordinary files, **with no encryption of their own**. Protection comes from
  your Windows account's permissions. On a laptop, use disk encryption
  (BitLocker).
- `settings.json` — preferences and the encrypted OpenAI key (see below).

Deleting a meeting in the app deletes its folder. **Discard audio** deletes only
the audio and keeps the transcript and minutes.

## The OpenAI key

- It is encrypted with **Windows DPAPI**, tied to your user account on that
  machine. Copying `settings.json` to another PC or another user doesn't reveal
  the key.
- If Windows doesn't offer encryption, the app **refuses to save** the key
  rather than storing it in readable form.
- The app's interface never receives the key: only the main process reads it,
  at the moment it calls the API.
- **Limitation:** any program running under your Windows account can ask DPAPI
  to decrypt it. This applies to every desktop app, including passwords saved in
  your browser.

Recommendations:

1. Create a key **exclusively** for Yogurt, in a separate OpenAI project.
2. Set a monthly **spending limit** on that project.
3. If the computer is compromised, **revoke** the key in the OpenAI dashboard.

## App protections

- The interface runs isolated: `contextIsolation`, `sandbox` and no
  `nodeIntegration`. It only talks to the system through a closed list of
  commands.
- Commands validate what they receive: meeting IDs and block numbers that don't
  match the expected format are rejected before they become a file path.
- A content security policy (CSP) blocks external scripts and connections in
  the interface; the window doesn't navigate away from the app.
- Links only open in the browser if they are `https`/`http`.
- The minutes generated by the model are rendered without interpreting HTML.
- The executable has Electron's *fuses* locked: it doesn't run as Node
  (`ELECTRON_RUN_AS_NODE`, `NODE_OPTIONS`, `--inspect` are ignored) and it
  verifies the integrity of `app.asar`.
- Dependencies are audited with `npm audit` on every release.

## The installer isn't signed

Windows shows *"Windows protected your PC"* on first run, because the installer
has no code signature (the certificate costs money). To trust the binary you
can:

- check the installer's SHA-256 against the one published on the release page
  (`Get-FileHash .\Yogurt-<version>-setup.exe`); or
- build it yourself from source (`npm install` and `npm run dist`; see the
  README).

## Recording people

Recording and transcribing a meeting involves personal data of every
participant. **Inform and obtain the consent** of everyone in the meeting, and
follow your organization's rules and the applicable law (such as the GDPR or
Brazil's LGPD).
